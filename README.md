# ArchyOS

Минималистичная операционная система с графическим интерфейсом, файловым менеджером и системными утилитами.

## Особенности

- 🖥️ Графический интерфейс на C++ с Qt
- 📁 Файловый менеджер
- 📊 Встроенный Neofetch
- ⚡ Основана на buildroot
- 🔧 Bootloader на ассемблере
- 💾 Минималистичное ядро

## Структура проекта

```
ArchyOS/
├── bootloader/          # Загрузчик на ассемблере
├── kernel/              # Ядро системы
├── gui/                 # GUI приложения (C++)
├── file-manager/        # Файловый менеджер
├── neofetch/            # Системная утилита
├── buildroot-config/    # Конфигурация buildroot
└── build/               # Скомпилированные файлы
```

## Требования

- gcc/g++
- make
- nasm (для ассемблера)
- buildroot
- Qt5 (для GUI)

## Сборка

```bash
make build-all
```
